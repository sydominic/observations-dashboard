# Optional local Korean fonts

This app does not use `packages.txt` / apt-get.

PDF Korean text is handled first by repo-local fonts in this folder, then by the pip dependency `koreanize-matplotlib`.

Optional filenames recognized by the app:
- NanumGothic.ttf
- NanumGothicBold.ttf
- NanumBarunGothic.ttf
- NotoSansKR-Regular.ttf
- NotoSansCJKkr-Regular.otf
- NotoSansCJK-Regular.ttc

Do not commit font files unless you have obtained them from the official distributor and keep the required license notice.
